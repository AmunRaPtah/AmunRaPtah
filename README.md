# Eniola Olutogun

**Computational scientist — validation-first models for drug safety and the brain.**

Computational neuroscience · AI & drug discovery · biomathematics · pharmacy (PCN-licensed, Nigeria).
My principle: validate before you believe, publish the method, and report what fails.

### Selected work
- **neurocascade** — a simulation engine for CNS drug discovery that predicts human PK, target
  engagement and liabilities from a compound's preclinical package. Public model card and
  validation ledger (engine private; available to reviewers on request):
  https://github.com/AmunRaPtah/neurocascade-summary
- **Topologix** — a pre-registered test of whether topological (persistent-homology) features of the
  drug–protein interface beat a cheap descriptor baseline. The gate did not pass on any endpoint;
  the repository is retained as an honest, pre-registered negative result:
  https://github.com/AmunRaPtah/topologix
- **CCT model** — a falsifiable, pre-registered dynamical/Bayesian model of reward-memory encoding
  in addiction.
