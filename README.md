# Eniola Olutogun

**Computational scientist — building validation-first models for drug safety and the brain.**

Computational neuroscience · AI & drug discovery · neural engineering · biomathematics · pharmacy.
I run **ZYCO Institute**. My principle: validate before you believe, publish the method, report what fails.

### Work
- **CCT model** — tripartite dynamical/Bayesian model of reward-memory encoding (addiction); falsifiable, pre-registered.
- **Topologix** — topological (persistent-homology) models of drug–protein interaction: drug-resistance prediction & hERG cardiotoxicity.
- **IMPRINT** — addiction-liability screening from receptor-binding profiles.
- **GATE** — open framework for safety in closed-loop neuromodulation.
